界面字体放置文件夹。

想加字体：把 .ttf / .otf / .woff / .woff2 文件丢进本文件夹，重启 ComfyUI 后，
在「外观定制器 -> 尺寸与透明度 -> 界面字体」下拉中选择即可。
字体显示名 = 文件名（不含扩展名）。删除文件后重启即从下拉消失。

内置两枚字体（Glass_TTY_VT220.ttf、MapleMonoNormal-NF-CN-Medium.ttf，
SIL OFL 1.1 授权，见 LICENSE-fonts.txt）随 Releases 的安装包分发；
用 git clone 安装的用户若想要字体，请到本仓库 Releases 页面下载后放入本文件夹。
